Built for messy experiments

Use SnapShots while you build and test on a local or development site. A restore replaces the current database and, when files were saved, the uploads directory. Plugins, themes, and WordPress core stay as they are.

Create & restore

  • Search the admin bar list by name. Ctrl+S opens the menu and focuses search. Enter restores the first match.
  • Stay logged in as the same user after a restore from the admin screen.
  • Keep two copies of the same name by default; older ones are removed automatically.
  • Confirm before every restore or delete.

Tools & settings

Tools → Snapshots lists every snapshot with name, created time, last used, and saved location. Select several rows and delete together.

Settings → Snapshots controls folder path, copy limit, uploads, return URL, excluded tables, and sort order. Linked from Plugins and the admin bar.

📁

Storage

wp-content/.snapshots by default. Override via UI or SNAPSHOTS_FOLDER.

⚙️

Overrides

Constants in wp-config.php win. Filters like snapshots_max_shots work too.

Inside every snapshot

dump.sql

Database export for site tables, minus any you exclude.

data.zip

Uploads folder when Save Files is on (default).

manifest.json

Name, timestamps, and optional return URL.

On restore, prefix tables not in the snapshot are dropped. Mismatched home URLs get a WP-CLI search-replace. Zip via ZipArchive or PclZip fallback.

Not an off-site backup. Snapshots live on this server only. Keep separate backups for anything you cannot lose.

wp snapshot 
$ wp snapshot backup "Before the experiment" --files
$ wp snapshot restore before-the-experiment
$ wp snapshot list
$ wp snapshot delete before-the-experiment

Automate with WP-CLI

backup accepts --files, --location=<path>, and --exclude_tables=<tables>.

restore and delete take a name, slug, or folder id like before-the-experiment_1587039434. Names use the latest copy.

For coding agents

Snapshot before risky work. List with --format=json. Restore only your task snapshot or when the user asks. Never delete unless asked.
